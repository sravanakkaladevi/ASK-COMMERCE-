# 👑 ASK — Handcrafted Silks | Ultra-Luxury E-Commerce Boutique

> **Woven in Heritage, Draped in Splendour.**  
> An ultra-luxury Next.js 16 e-commerce web application honoring centuries of authentic Indian handloom heritage — direct from master karigars in Varanasi, Kanchipuram, and Hyderabad.

---

## 🌟 Key Features & Interactive Architecture

### 🎬 Ambient Video Hero & Runway Showcase
- **HD Video Background**: Auto-playing ambient intro video (`intro-video.mp4`) with smooth high-contrast vignettes.
- **Floating Glassmorphic Navbar**: Transparent top header floating over hero video that morphs into a sticky dark glassmorphic navigation bar on scroll with auto-collapsing announcement bar.
- **Runway & Atelier Documentary Modal**: Interactive video player popup ("Watch Loom Film") with live time-elapsed tracker, progress bar, play/pause, and sound mute/unmute controls.

### 🧵 Master Weaver Handloom Section (`#craft`)
- **Live Handloom Weaving Stream**: Live loop of Varanasi & Kanchipuram Master Karigars operating traditional pit-looms (`weaver-handloom.mp4`).
- **Interactive Swatch Switcher**: Macro fabric swatches for Varanasi Kadwa Brocade, Kanchipuram Pure Zari, Molten Organza, and Chanderi Silk.

### 🎨 Endless Auto-Scrolling Marquee & Carousels
- **SIX MOODS Palette**: Continuous, infinite horizontal marquee track (`x: ["-50%", "0%"]`) showcasing Arched Mood Cards (Festive, Bridal, Cocktail, Morning Puja, Reception, Sangeet), pausing smoothly on hover.
- **Silk Archives Carousel ("Woven to Be Remembered")**: Infinite auto-scrolling track for rare heirloom drapes with Quick View and Add to Bag overlays.

### 💃 Interactive "Change Look" Saree Swapper
- Real-time swatch color switcher letting customers instantly preview saree drape variations with matching blouse details.

### 🛡️ Atelier Services & Modal Suite
- **Pure Zari Testing Guide Modal**: 3-step Hallmark & Scratch/Burn verification guide with lifetime buyback warranty.
- **Silk Care & Storage Protocol Modal**: Unbleached muslin wrap, fold rotation, and dry cleaning conservation guidelines.
- **Track Your Order Modal**: Live AWB logistics lookup & transit tracking.
- **Worldwide Shipping & Returns Modal**: Duty-prepaid air freight & 7-day no-questions return policy.

## 🛠️ Technology Stack

- **Framework**: [Next.js 16.4](https://nextjs.org/) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev/)
- **Language**: TypeScript 5
- **Styling**: [TailwindCSS v4](https://tailwindcss.com/) & Custom Luxury CSS Tokens
- **Animations & Physics**:
  - [Framer Motion 14](https://www.framer.com/motion/) (Infinite marquee loops, spring drawers, layout transitions)
  - [GSAP 3](https://gsap.com/) & ScrollTrigger
  - [Lenis 1.3](https://lenis.darkroom.engineering/) (Smooth wheel scrolling inertia)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Visual Assets**: High-definition MP4 videos & custom generated AI luxury silk photography.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js 20+ installed on your machine.

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/sravanakkaladevi/ASK-COMMERCE-.git

# Change directory
cd ASK-COMMERCE-

# Install dependencies
npm install
```

### 3. Development Server
Run the local dev server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Production Build
To create an optimized production build:
```bash
npm run build
npm run start
```
